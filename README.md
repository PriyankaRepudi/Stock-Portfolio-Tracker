# Stock Portfolio Tracker

A console application that totals the value of selected stocks using a hardcoded dictionary of sample prices.

## Requirements
- Python 3.8 or newer
- No external packages

## Run
```bash
python main.py
```

## Use
- Select stock symbols shown by the program.
- Enter a positive whole-number quantity for each symbol.
- Enter `DONE` to see the portfolio total.
- Optionally save the result to `portfolio.csv`.

## Important
The prices are illustrative hardcoded values in USD. They are not live prices or investment advice.

## Concepts used
Dictionaries, loops, input validation, arithmetic, functions, CSV file handling.
